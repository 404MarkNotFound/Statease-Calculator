# Statease Calculator

A browser-based calculator for the mean, median, and mode of a data set.

## Project files

- `index.html` — page content
- `css/style.css` — page styling
- `js/script.js` — calculator and page behavior
- `images/` — team member photos
- `original.html` — original single-file version

Open `index.html` in a browser to use the calculator.
